# ByteSpace Landing Page

A responsive learning platform landing page built with React and Tailwind CSS.

## Features

- Responsive navigation
- Hero section with course search
- Partner logos
- Course categories and learning paths
- Professional growth section
- Creator CTA
- Testimonials
- Responsive footer

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Component Structure

- Navbar
- Hero
- PartnerLogos
- CourseSection
- GrowthSection
- CreatorCTA
- Testimonials
- Footer
